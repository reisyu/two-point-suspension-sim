# 2点吊りシミュレーション（2D）

剛体を2本の伸びない糸で吊ったときの挙動を扱う、依存ライブラリなしの単一HTMLシミュレータです。ブラウザで [two-point-2d.html](two-point-2d.html) を開くだけで動きます。

## できること

- **動力学**：XPBD（位置ベース）による剛体シミュレーション。糸は片側拘束（張力は押せない）、減衰つき。
- **つり合い解の列挙**：2本とも張った状態を四節リンクとみなし、重心高さ y_G の局所極小をすべて探索。各解の張力を計算し、負のもの（物理的に不可）を除外。
- **吊り点・取付点の数値指定**：アンカー A₁/A₂（世界座標）と物体側の取付点 a₁/a₂（ローカル座標）を直接入力、またはドラッグで指定。
- **巻き上げ手順（ステップ再生）**：各ステップで到達させたい糸の長さ・速度・静定待ち時間を指定し、通し再生／1ステップずつ実行。準静的な重心経路を連続法で先に計算して重ねて表示。
- **掃引形状の表示**：手順全体で物体が通過する領域をシルエットで表示。最左点・最右点の軌跡、掃引の限界線も。
- **角度の表示**：糸の鉛直からの傾き、取付点線（a₁→a₂）の水平からの傾きを作図・数値・グラフで表示。
- **CAD（DXF）読み込み**：ASCII DXF を読み込み、レイヤーで「外形」「糸」「重心」を指定。単位は m を既定とし、読み込み後もプルダウンで変換可能。
- **メニューの折りたたみ**：各セクションを開閉して画面を整理。

## 使い方

1. `two-point-2d.html` をブラウザで開く
2. 形状を選ぶか、DXFを読み込む
3. 吊り点・取付点・糸の長さを調整
4. 「ステップ（巻き上げ手順）」で巻き上げ計画を組んで再生

## ファイル構成

- `two-point-2d.html` — シミュレータ本体（単一HTMLファイル）
- `sample.dxf` — DXF読み込みの動作確認用サンプル図面
